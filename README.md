# ربات سیگنال کریپتو -> تلگرام (کاملاً رایگان)

این پروژه دو استراتژی (EMA+RSI+MACD و Supertrend+ADX) را روی داده‌ی رایگان بایننس اجرا می‌کند
و سیگنال خرید/فروش را مستقیم در تلگرام برایت می‌فرستد. هیچ هزینه‌ای ندارد (نه TradingView، نه سرور).

## مرحله ۱: ساخت ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بفرست و یک اسم و یوزرنیم برای ربات انتخاب کن.
3. BotFather یک **توکن** به شکل `123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ` می‌دهد. آن را جایی ذخیره کن.

## مرحله ۲: پیدا کردن Chat ID

1. با ربات جدیدی که ساختی یک پیام (مثلاً `سلام`) بفرست.
2. در مرورگر این آدرس را باز کن (به‌جای `<TOKEN>` توکن خودت را بگذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. در خروجی JSON دنبال `"chat":{"id": ...}` بگرد؛ آن عدد Chat ID توست.
   (اگر می‌خواهی سیگنال به یک کانال/گروه برود، ربات را ادمین آن کانال/گروه کن و آیدی همان کانال/گروه را بردار.)

## مرحله ۳: آپلود پروژه در گیت‌هاب

1. یک ریپازیتوری جدید و **خصوصی (Private)** در گیت‌هاب بساز.
2. تمام فایل‌های این پوشه (`signal_bot.py`, `requirements.txt`, `state.json`, پوشه `.github`) را در آن آپلود کن.

## مرحله ۴: تنظیم Secrets (توکن و چت‌آیدی را مخفی نگه دار)

در ریپازیتوری گیت‌هاب:
`Settings -> Secrets and variables -> Actions -> New repository secret`

دو مقدار زیر را اضافه کن:
- `TELEGRAM_BOT_TOKEN` → همان توکنی که از BotFather گرفتی
- `TELEGRAM_CHAT_ID` → همان Chat ID مرحله‌ی قبل

## مرحله ۵: فعال‌سازی اجرای خودکار

1. به تب **Actions** ریپازیتوری برو و اجرای Workflow ها را فعال کن.
2. ورک‌فلو `Crypto Signal Bot` هر ۱۵ دقیقه خودش اجرا می‌شود (کاملاً رایگان روی GitHub Actions).
3. برای تست فوری، می‌توانی از همان تب Actions، روی workflow کلیک کنی و دکمه‌ی
   **Run workflow** را بزنی تا همین الان یک‌بار اجرا شود.

## شخصی‌سازی

فایل `signal_bot.py` را باز کن، بالای فایل بخش تنظیمات هست:

- `SYMBOLS` → لیست نمادهایی که می‌خواهی رصد شوند (فرمت بایننس، مثل `"BTCUSDT"`)
- `TIMEFRAME` → تایم‌فریم (`"15m"`, `"1h"`, `"4h"` و ...)
- بقیه‌ی پارامترها (طول EMA، آستانه‌ی ADX و غیره) دقیقاً معادل همان چیزی هستند که در Pine Script تنظیم کرده بودیم.

## نکات مهم

- این پروژه فقط **سیگنال** می‌فرستد و خودش معامله نمی‌کند (بدون ریسک اجرای خودکار سفارش).
- داده از API عمومی بایننس گرفته می‌شود؛ اگر می‌خواهی از صرافی دیگری (مثل کوکوین یا کراکن) استفاده کنی، فقط باید تابع `get_klines` عوض شود.
- چون GitHub Actions هر ۱۵ دقیقه اجرا می‌شود، سیگنال‌ها با کمی تاخیر (حداکثر چند دقیقه) نسبت به لحظه‌ی بسته‌شدن کندل می‌رسند؛ برای اسکالپ خیلی سریع کافی نیست ولی برای اکثر استفاده‌ها مناسبه.
- این ابزار فقط کمک تحلیلی است، نه توصیه‌ی سرمایه‌گذاری. همیشه با مدیریت ریسک معامله کن.
