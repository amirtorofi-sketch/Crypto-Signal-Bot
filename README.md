# ربات سیگنال کریپتو -> تلگرام (کاملاً رایگان)

این پروژه دو استراتژی (EMA+RSI+MACD و Supertrend+ADX) را روی داده‌ی رایگان بایننس اجرا می‌کند
و سیگنال خرید/فروش را مستقیم در تلگرام برایت می‌فرستد. هیچ هزینه‌ای ندارد (نه TradingView، نه سرور).

## مرحله ۱: ساخت ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بفرست و یک اسم و یوزرنیم برای ربات انتخاب کن.
3. BotFather یک **توکن** به شکل `123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ` می‌دهد. آن را جایی ذخیره کن.

## مرحله ۲: پیدا کردن Chat ID

1. با ربات جدیدی که ساختی یک پیام (مثلاً `سلام`) بفرست.
2. در مرورگر این آدرس را باز کن (به‌جای `<TOKEN>` توکن خودت را بگذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. در خروجی JSON دنبال `"chat":{"id": ...}` بگرد؛ آن عدد Chat ID توست.
   (اگر می‌خواهی سیگنال به یک کانال/گروه برود، ربات را ادمین آن کانال/گروه کن و آیدی همان کانال/گروه را بردار.)

## مرحله ۳: آپلود پروژه در گیت‌هاب

1. یک ریپازیتوری جدید و **خصوصی (Private)** در گیت‌هاب بساز.
2. تمام فایل‌های این پوشه (`signal_bot.py`, `requirements.txt`, `state.json`, پوشه `.github`) را در آن آپلود کن.

## مرحله ۴: تنظیم Secrets (توکن و چت‌آیدی را مخفی نگه دار)

در ریپازیتوری گیت‌هاب:
`Settings -> Secrets and variables -> Actions -> New repository secret`

دو مقدار زیر را اضافه کن:
- `TELEGRAM_BOT_TOKEN` → همان توکنی که از BotFather گرفتی
- `TELEGRAM_CHAT_ID` → همان Chat ID مرحله‌ی قبل

## مرحله ۵: فعال‌سازی اجرای خودکار

1. به تب **Actions** ریپازیتوری برو و اجرای Workflow ها را فعال کن.
2. ورک‌فلو `Crypto Signal Bot` هر ۱۵ دقیقه خودش اجرا می‌شود (کاملاً رایگان روی GitHub Actions).
3. برای تست فوری، می‌توانی از همان تب Actions، روی workflow کلیک کنی و دکمه‌ی
   **Run workflow** را بزنی تا همین الان یک‌بار اجرا شود.

## شخصی‌سازی

فایل `signal_bot.py` را باز کن، بالای فایل بخش تنظیمات هست:

- `SYMBOLS` → لیست نمادهایی که می‌خواهی رصد شوند (فرمت بایننس، مثل `"BTCUSDT"`)
- `TIMEFRAME` → تایم‌فریم (`"15m"`, `"1h"`, `"4h"` و ...)
- بقیه‌ی پارامترها (طول EMA، آستانه‌ی ADX و غیره) دقیقاً معادل همان چیزی هستند که در Pine Script تنظیم کرده بودیم.

## نکات مهم

- این پروژه فقط **سیگنال** می‌فرستد و خودش معامله نمی‌کند (بدون ریسک اجرای خودکار سفارش).
- داده از API عمومی بایننس گرفته می‌شود؛ اگر می‌خواهی از صرافی دیگری (مثل کوکوین یا کراکن) استفاده کنی، فقط باید تابع `get_klines` عوض شود.
- چون GitHub Actions هر ۱۵ دقیقه اجرا می‌شود، سیگنال‌ها با کمی تاخیر (حداکثر چند دقیقه) نسبت به لحظه‌ی بسته‌شدن کندل می‌رسند؛ برای اسکالپ خیلی سریع کافی نیست ولی برای اکثر استفاده‌ها مناسبه.
- این ابزار فقط کمک تحلیلی است، نه توصیه‌ی سرمایه‌گذاری. همیشه با مدیریت ریسک معامله کن.

## اتصال به صرافی تبدیل (Tabdeal) برای اجرای واقعی با مبلغ کم

این بخش زیرساخت اتصال به صرافی ایرانی **تبدیل** را اضافه می‌کند تا در آینده
بتوانی با مبلغ خیلی کم (مثلاً ۱۰۰-۲۰۰ هزار تومان هر پوزیشن) واقعی تست کنی.

**⚠️ وضعیت فعلی: این زیرساخت به هیچ‌کدام از `trading_bot.py` / `trading_bot_v2.py`
وصل نشده و خودکار هیچ سفارشی نمی‌زند.** فقط ابزارهای لازم آماده‌اند تا وقتی خودت
تصمیم گرفتی، دستی و آگاهانه استفاده‌شان کنی.

### فایل‌های جدید
- `tabdeal_client.py` — کلاینت خام API تبدیل (امضای HMAC-SHA256، ثبت سفارش، سفارش OCO، موجودی)
- `tabdeal_executor.py` — تبدیل سیگنال (قیمت‌های دلاری بایننس) به سفارش واقعی تومانی روی تبدیل، با قفل‌های ایمنی
- `tabdeal_test_connection.py` — تست **فقط‌خواندنی**: پینگ سرور + قیمت لحظه‌ای + موجودی حساب. هیچ سفارشی ثبت نمی‌کند.
- `.github/workflows/tabdeal_test.yml` — ورک‌فلوی جدا که فقط با کلیک دستی (`workflow_dispatch`) اجرا می‌شود؛ در زمان‌بندی خودکار قرار ندارد.

### یافته‌ی مهم درباره‌ی API تبدیل
API عمومی تبدیل **کندل تاریخی (kline/OHLCV) ندارد** - فقط order book و لیست
معاملات اخیر. به همین دلیل تحلیل و سیگنال‌گیری همچنان از بایننس می‌آید
(`signal_bot.py` بدون تغییر)؛ تبدیل فقط برای **اجرای واقعی سفارش** و گرفتن
قیمت لحظه‌ای استفاده می‌شود.

چون بازارهای تبدیل تومانی هستند ولی سیگنال‌ها دلاری (USDT) محاسبه می‌شوند،
`tabdeal_executor.py` به‌جای قیمت مطلق، **فاصله‌ی درصدی** حد ضرر/حد سود نسبت
به ورود را از سیگنال می‌گیرد و همان درصد را روی قیمت لحظه‌ای واقعی تبدیل
پیاده می‌کند.

### گام ۱: گرفتن API Key از تبدیل
1. وارد حساب کاربری‌ات در tabdeal.org شو.
2. از تنظیمات پروفایل، بخش API را پیدا کن و یک کلید جدید بساز.
3. **`api-secret` فقط همان لحظه‌ی ساخت نمایش داده می‌شود** - همان‌جا کپی و
   جای امن ذخیره‌اش کن.
4. اگر گزینه‌ی محدودکردن کلید به یک IP خاص دیدی، **آن را روشن نکن** مگر
   بخواهی به‌جای GitHub Actions از یک سرور با IP ثابت استفاده کنی - چون
   IP اجراهای GitHub Actions هر بار عوض می‌شود.

### گام ۲: تنظیم Secrets در گیت‌هاب
`Settings -> Secrets and variables -> Actions -> New repository secret`:
- `TABDEAL_API_KEY`
- `TABDEAL_API_SECRET`

(اختیاری، برای تغییر پیش‌فرض‌ها می‌توانی این‌ها را هم به‌عنوان Variables یا
Secrets اضافه کنی: `TABDEAL_DRY_RUN` پیش‌فرض `true`، `TABDEAL_MAX_POSITION_IRT`
پیش‌فرض `200000`.)

### گام ۳: تست اتصال (فقط خواندنی)
از تب **Actions** ریپو، روی ورک‌فلوی **Tabdeal Connection Test** بزن →
**Run workflow**. اگر همه‌چیز درست باشد، باید موجودی حسابت (حتی صفر) و
قیمت لحظه‌ای چند بازار نمونه را ببینی - بدون این‌که هیچ سفارشی ثبت شود.

می‌توانی محلی هم تست کنی:
```bash
export TABDEAL_API_KEY="..."
export TABDEAL_API_SECRET="..."
python tabdeal_test_connection.py
```

### گام ۴ (بعداً، وقتی خودت تصمیم گرفتی): اجرای واقعی یک پوزیشن نمونه
```python
from tabdeal_executor import get_client, build_execution_plan, execute_plan

client = get_client()
plan = build_execution_plan(
    client, binance_symbol="BTCUSDT", direction="long",
    signal_entry=100.0, signal_sl=98.0, signal_tp=104.0,
    max_position_irt=150_000,   # هیچ‌وقت از TABDEAL_MAX_POSITION_IRT بیشتر نمی‌شود
)
print(plan)
execute_plan(client, plan)   # اگر TABDEAL_DRY_RUN=true باشد، فقط چاپ می‌کند و سفارش نمی‌فرستد
```
پیش از خاموش‌کردن `TABDEAL_DRY_RUN`، حتماً چند بار با آن روشن اجرا کن و
خروجی `describe_plan` را بررسی کن تا از درستی محاسبه‌ی قیمت/حجم مطمئن شوی.

### نگاشت نمادها
لیست `SYMBOL_MAP` در `tabdeal_executor.py` نمادهای بایننس را به بازارهای
تبدیل نگاشت می‌کند (مثلاً `BTCUSDT` → `BTCIRT`). قبل از استفاده‌ی واقعی،
نام دقیق بازارها را با `client.exchange_info()` از خودِ تبدیل تایید کن.
